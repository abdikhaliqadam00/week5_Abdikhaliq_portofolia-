## Understand the code
Semantic elements describe each part of the page. A link such as href="#projects" moves to id="projects". Flexbox puts sections side by side. Media queries at 900px and 600px change the layout. box-sizing includes padding and borders in element width. The details/summary elements open notes without JavaScript. Focus outlines support keyboard navigation. Reduced-motion settings remove scrolling animation and button motion.
